# Late Again! - Godot 3D Demo

เดโม Endless Runner 3D ที่ใช้ primitive ของ Godot ทั้งหมด ไม่ต้องดาวน์โหลด asset เพิ่ม

## แก้ฉากแบบลากวางได้

- `Main.tscn` มีถนน กล้อง แสง อาคาร และ UI
- `Player.tscn` มีตัวละคร
- `Obstacle.tscn` มีสิ่งกีดขวาง
- `Coin.tscn` มีเหรียญ

ดับเบิลคลิก Scene เหล่านี้ใน FileSystem เพื่อแก้ทรง สี ขนาด หรือตำแหน่งผ่าน Inspector ได้เลย ส่วน `main.gd` เหลือไว้ปรับกติกา ความเร็ว การกระโดด และการเกิดวัตถุ

## วิธีเปิด

1. เปิด **Godot 4.7** (หรือ Godot 4.x)
2. กด **Import** แล้วเลือกไฟล์ `project.godot` ในโฟลเดอร์นี้
3. กดปุ่ม **Play** หรือ `F6/F5`

## การควบคุม

- `←` / `→` เปลี่ยนเลน
- `Space` หรือ `↑` กระโดด
- เก็บลูกกลมสีเหลืองเพื่อรับ 10 คะแนน
- หลบแบริเออร์สีแดง; ชนแล้วจบเกม
- กดปุ่ม **Restart** หรือ `R` เพื่อเริ่มใหม่

## โครงเดโม

- ตัวละครวิ่งต่อเนื่องในมุมกล้องบุคคลที่สาม
- สลับได้ 3 เลน
- สิ่งกีดขวางและดาว/เหรียญจะเกิดมาเรื่อย ๆ
- ถนนและตึกสร้างจากกล่อง, ตัวละครจาก Capsule และ Sphere
